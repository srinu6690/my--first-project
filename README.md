# Student Performance & Study Analytics Dashboard 📊

An advanced, interactive dark-themed Excel dashboard designed to track, analyze, and visualize student academic performance, study hours, attendance, and assignment completion rates.

## 🚀 Project Overview
This project provides a comprehensive data analytics solution built entirely in Microsoft Excel. It transforms raw student data into actionable insights through dynamic KPIs, interactive Slicers, custom pivot tables, native Excel hyperlinks, and smart VBA automation.

## ✨ Key Features & Components
- **Interactive Dark-Themed UI:** Designed with a modern dark mode aesthetic for reduced eye strain and a clean layout.
- **Dynamic Slicers:** Seamlessly filter data by **Student** and **Subject** to instantly update metrics across the dashboard.
- **KPI Summary Cards:** Displays crucial metrics including:
  - Total Students & Total Study Hours
  - Average Scores & Attendance Percentages
  - Assignment Completion Rates & At-Risk Students Tracking
- **Seamless Navigation & VBA Automation:** 
  - **Document Hyperlinks:** Built-in "Place in This Document" links for smooth and quick tab navigation across the workbook.
  - **Reset Slicers:** One-click clear all filters to restore default view.
  - **KPI Color Customization:** Dynamic theme toggle/color changing for KPI cards.
  - **Back to Top:** Quick smooth navigation back to the top of the dashboard.
- **Structured Workbook Architecture:** Organized into dedicated tabs for seamless data management:
  - `06_Dashboard`: Main visual control center.
  - `01_Raw_Data`: Source dataset storage.
  - `03_Calculations`: Backend processing formulas (`XLOOKUP`, `INDEX/MATCH`, `SUMIFS`, `AVERAGEIFS`, etc.).
  - `04_Pivot`: Dynamic aggregation tables.
  - `05_Reports`: Summary reporting layout.
  - `02_Master_Data`: Lookup and validation lists.

## 🛠️ Tools & Technologies Used
- **Microsoft Excel:** Advanced Formulas, Pivot Tables, Pivot Charts, Conditional Formatting, Data Validation, and Hyperlinks.
- **VBA Macros:** Automating slicer resets, KPI color styling, and Back to Top functionality.
- **Data Analytics:** KPI structuring, performance tracking, and metric evaluation.

## 📁 How to Use
1. Download the `.xlsm` project file from this repository.
2. Open it in Microsoft Excel (ensure macros are enabled for VBA functionality).
3. Use the top navigation links, Slicers, Reset Slicers button, and KPI controls to explore the analytics dynamically.
